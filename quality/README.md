# Workspace publication metadata

| File | Purpose |
| --- | --- |
| [publication.json](publication.json) | Current tracked-file inventory, original/public hashes, exact relocations and reasons historical files are unavailable |
| [privacy-allowlist.json](privacy-allowlist.json) | Exact reviewed artifact hashes for the privacy gate; no personal-identifier exemption |
| [privacy-redactions.json](privacy-redactions.json) | Recorded privacy cleanup of historical publications |

Experiment ledgers and methods belong to their projects. The
[OS ledger](../projects/os-evaluation/quality/evidence.json) and
[method definitions](../projects/os-evaluation/quality/methods) preserve original
declarations. Wireless maintains its [functional evidence](../projects/wireless-explorer/results/README.md)
under its own project.

The [assurance workflow](../docs/assurance-workflow.md) defines evidence gates.
The [ownership and retention policy](../docs/organization.md) explains where
records belong and which historical/generated material remains useful.
